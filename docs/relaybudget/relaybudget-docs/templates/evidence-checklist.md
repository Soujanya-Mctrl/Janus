# Implementation and submission evidence checklist

All entries begin unchecked; checking a box requires a real artifact.

## Core

- [ ] Exact dependency/tool versions and lockfiles
- [ ] Independent accounting model and passing property tests
- [ ] Stale new reservation rejected after assignment change
- [ ] Prior reservation honored or expired according to contract
- [ ] Lost-response scenario reuses paid result
- [ ] B/C/D continue during A-specific fault
- [ ] Independent owner exit with backend, DB, facilitator, and registry stopped
- [ ] Public financial state and remaining trust assumptions disclosed

## Sponsor

- [ ] Current event and partner rules rechecked
- [ ] x402 method support and executor admission recorded
- [ ] Live protected payment and actual merchant credit verified
- [ ] Transaction ID and HashScan link recorded
- [ ] Arkiv writer address, entity, and real discovery query recorded
- [ ] Arkiv schema/friction/reach/why/how files complete
- [ ] FOSS license, CROPS section, no client trackers
- [ ] AI assistance and reused components attributed
- [ ] Three-minute truthful demo and actual architecture diagram

## Evaluation and release

- [ ] Strong baseline includes current x402 identifiers and durable result store
- [ ] Fault seeds and raw failed trials preserved
- [ ] Manifest and results table populated from measurements
- [ ] Security findings reproduced and fixed or disclosed
- [ ] Fresh checkout reproduces setup and recovery
- [ ] No production readiness, market traction, privacy, or audit claim beyond evidence
